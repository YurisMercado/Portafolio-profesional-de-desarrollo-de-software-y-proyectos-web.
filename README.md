# Portafolio de Yuriannys Mercado

Portafolio personal de desarrollo de software, desarrollado con HTML, CSS y JavaScript sin dependencias.

## Ejecutar localmente

Abre `index.html` en tu navegador o utiliza la extensión Live Server de Visual Studio Code.

## Proyectos incluidos

- Plataforma POS, hotel y restaurante.
- Sistema de gestión de mantenimiento.
- Sistema administrativo de asociados ASOINPECAR.
- Sistema de carnetización con QR.

Las descripciones no implican que el código fuente de proyectos organizacionales tenga autorización para publicarse.

## Antes de publicar

- Agrega tu correo profesional y URL real de GitHub/LinkedIn.
- Verifica las descripciones y atribución de cada proyecto.
- Incorpora capturas anonimizadas solo si tienes autorización.
- No publiques `.env`, claves, bases de datos reales, información de huéspedes, trabajadores o clientes.

## Publicar en GitHub

1. Crea un repositorio público llamado `portafolio`.
2. En esta carpeta ejecuta:

```bash
git init
git add .
git commit -m "Crear portafolio profesional"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/portafolio.git
git push -u origin main
```

3. En GitHub ve a **Settings > Pages**, selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**.
4. Visita `https://TU_USUARIO.github.io/portafolio/` cuando GitHub Pages complete la publicación.

Nota: configura primero tus credenciales de Git/GitHub. No reemplaces TU_USUARIO sin conocer tu nombre real de usuario.
