## Publicar en mi repositorio existente

Ya existe un repositorio de GitHub bajo el usuario [YurisMercado](https://github.com/YurisMercado). **No necesitas crear otro repositorio ni ejecutar `git init`** para actualizar la página desde la interfaz web.

1. Abre tu repositorio actual del portafolio en GitHub.
2. En la pestaña **Code**, entra a `index.html` y pulsa el ícono del lápiz (**Edit this file**), o usa **Add file > Upload files** para subir el archivo actualizado.
3. Para actualizar también esta documentación, sustituye `README.md` usando el mismo procedimiento.
4. Confirma los cambios con **Commit changes**.
5. En **Settings > Pages**, establece **Deploy from a branch**, rama `main` y directorio `/(root)`; guarda los cambios. GitHub Pages publicará `index.html`.
6. La URL será `https://YurisMercado.github.io/NOMBRE-EXACTO-DEL-REPOSITORIO/`. Para obtenerla sin errores, usa el enlace **Visit site** en Settings > Pages.

## Antes de compartir públicamente

- Comprueba que autorizas la publicación de tu correo y teléfono en la web, ya que cualquier visitante podrá verlos.
- Verifica autoría, permisos y material audiovisual de cada proyecto.
- No subas `.env`, contraseñas, claves, bases de datos de producción ni datos personales de clientes, empleados o usuarios.
- Publica versiones demostrativas con información ficticia cuando el código del trabajo sea privado.
